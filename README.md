# Ryanair Flight Price Tracker Bot

A Python bot that monitors Ryanair flight prices from Tallinn (TLL) to Nuremberg (NUE) and sends email + Telegram alerts when prices drop.

## Features
- ✈️ Checks Ryanair prices every hour
- 📧 Email alerts when price drops
- 💬 Telegram notifications
- 📊 Stores price history in SQLite database
- 📈 Price trend analysis
- ☁️ Runs 24/7 on Railway cloud
